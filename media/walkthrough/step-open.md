# Every function gets a grade

As soon as you open a supported file, a one-line summary appears above each function:

```
🟡 Needs attention · cyclomatic 12 · cognitive 18 · time O(n²) · space O(n)
def find_duplicates(items):
```

- The **grade** (A–D) and its colour tell you at a glance whether the function is fine.
- The gutter icon and the Problems panel show the same information.
- The **Complexity Guard** view in the activity bar lists every function, worst first.

Analysis runs locally while you type. Nothing leaves your machine, and no account or API key is needed.
